# Honker – prebuilt sqlite extensions

This repo provides an automated workflow to build the [Honker](https://honker.dev) sqlite extension for multiple architectures.

Use the following (static) links to directly download the extension:

- [**All (zip)**](https://github.com/avo7/honker-build/releases/download/latest/libhonker_ext.zip)
- [Linux](https://github.com/avo7/honker-build/releases/download/latest/libhonker_ext-linux-x86_64.so)
- [MacOS arm64](https://github.com/avo7/honker-build/releases/download/latest/libhonker_ext-macos-arm64.dylib)
- [MacOS intel](https://github.com/avo7/honker-build/releases/download/latest/libhonker_ext-macos-x86_64.dylib)
- [Windows](https://github.com/avo7/honker-build/releases/download/latest/libhonker_ext-windows-x86_64.dll)
